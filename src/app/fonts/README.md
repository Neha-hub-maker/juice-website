# Fonts

These Latin variable WOFF2 files are self-hosted through `next/font/local`.

- Fraunces: display face, copied from the pinned `@fontsource-variable/fraunces` package.
- DM Sans: body face, copied from the pinned `@fontsource-variable/dm-sans` package.

Each font's SIL Open Font License is included here. Fontsource packages are retained as development dependencies for provenance and reproducible updates. Builds do not fetch fonts from Google, and browsers request them from this site.
